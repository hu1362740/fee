# 开发环境配置与运行指南

## 一、项目概述

**Fee（灯塔）** 是一个轻量级前端监控系统，支持私有化部署。系统由三个核心模块组成：

- **Server（服务端）**：Node.js + Express 后端服务，负责数据接收、处理、存储和API提供
- **Client（客户端）**：Vue.js 前端管理界面，用于数据展示和配置管理
- **SDK（埋点库）**：JavaScript SDK，用于前端错误采集和性能监控

## 二、系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        前端应用（SDK）                            │
│  - 错误监控（JS异常、资源错误、HTTP错误）                        │
│  - 性能监控（页面加载、渲染时间）                                │
│  - 用户行为（PV、UV、停留时长）                                  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
                    ┌──────────────────┐
                    │   Nginx/Kafka    │
                    │   日志收集层      │
                    └──────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                      Server（Node.js）                          │
│  - SaveLog：日志解析入库                                         │
│  - Parse：数据解析处理                                           │
│  - Summary：数据汇总统计                                         │
│  - WatchDog：报警监控                                            │
│  - Task:Manager：任务调度                                        │
└─────────────────────────────────────────────────────────────────┘
                              ↓
                    ┌──────────────────┐
                    │  MySQL + Redis   │
                    │   数据存储层      │
                    └──────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                   Client（Vue.js）                              │
│  - 数据可视化展示                                                │
│  - 报警配置管理                                                  │
│  - 项目权限管理                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 四、Windows 环境搭建

### 4.1 安装基础软件

#### 4.1.1 安装 Node.js

1. 访问 [Node.js 官网](https://nodejs.org/) 下载 LTS 版本
2. 运行安装程序，按默认选项安装
3. 验证安装：
   ```powershell
   node -v
   npm -v
   ```

#### 4.1.2 安装 MySQL

1. 下载 [MySQL Installer](https://dev.mysql.com/downloads/installer/)
2. 选择 "Developer Default" 安装类型
3. 设置 root 密码（例如：`123456`）
4. 验证安装：
   ```powershell
   mysql -u root -p
   ```

#### 4.1.3 安装 Redis

**方法1：使用 Windows 版 Redis**
1. 下载 [Windows版Redis](https://github.com/tporadowski/redis/releases)
2. 解压到任意目录（例如：`D:\redis`）
3. 运行 `redis-server.exe`

**方法2：使用 Docker**
```powershell
docker run -d --name redis -p 6379:6379 redis:latest
```

验证安装：
```powershell
redis-cli ping
# 应返回 PONG
```

#### 4.1.4 安装 Nginx（可选）

1. 下载 [Nginx Windows版](http://nginx.org/en/download.html)
2. 解压到任意目录（例如：`D:\nginx`）
3. 启动 Nginx：
   ```powershell
   cd D:\nginx
   nginx.exe
   ```

### 4.2 克隆项目

```powershell
# 创建项目目录
mkdir D:\projects
cd D:\projects

# 克隆代码
git clone https://github.com/LianjiaTech/fee.git

```

### 4.3 配置 Server

#### 4.3.1 配置 MySQL

编辑 `server/src/configs/mysql.js`：

```javascript
const development = {
  host: '127.0.0.1',        // 主机地址
  port: '3306',             // 数据库端口
  user: 'root',             // 数据库用户名
  password: '123456',       // 数据库密码（修改为你的密码）
  database: 'platform'      // 数据库库名
}
```

#### 4.3.2 配置 Redis

编辑 `server/src/configs/redis.js`：

```javascript
const development = {
  host: '127.0.0.1',        // 主机地址
  port: '6379'              // Redis端口
}
```

#### 4.3.3 配置通用选项

编辑 `server/src/configs/common.js`：

```javascript
const development = {
  loginType: 'normal',      // 登录类型：normal（普通登录）或 uc（内部UC登录）
  use: {
    kafka: false,           // 是否使用Kafka（开发环境建议设为false）
    alarm: false            // 是否启用报警功能
  },
  nginxLogFilePath: 'D:/nginx/logs/'  // Nginx日志文件路径（根据实际情况修改）
}
```

**重要说明：**
- 如果没有安装 Kafka，将 `kafka` 设为 `false`，系统会使用 Nginx 日志方式
- 如果不需要报警功能，将 `alarm` 设为 `false`
- `nginxLogFilePath` 必须使用正斜杠 `/`，不能用反斜杠 `\`

### 4.4 初始化数据库

#### 4.4.1 创建数据库

```sql
-- 登录MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE platform DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 4.4.2 生成初始化SQL

在 `server` 目录下执行：

```powershell
cd server
npm run fee Utils:GenerateSQL 1 '2020-01' '2020-07' > init.sql
```

**参数说明：**
- `1`：项目ID
- `'2020-01'`：起始月份（YYYY-MM格式）
- `'2020-07'`：结束月份（YYYY-MM格式）

#### 4.4.3 执行初始化SQL

1. 打开生成的 `init.sql` 文件
2. **删除前两行**（这两行是命令输出，不是SQL语句）
3. 将剩余内容复制到 MySQL 客户端执行

或使用命令行：
```powershell
# 删除前两行后执行
mysql -u root -p platform < init.sql
```

#### 4.4.4 初始化样例数据

```powershell
npm run fee Utils:TemplateSQL
```

执行成功后，会向数据库写入样例数据，方便开发调试。

```powershell

**说明：**

### 4.8 Windows 特殊配置

#### 4.8.1 Nginx 日志分割

Windows 系统不支持 `logrotate`，需要使用内置的 `Utils:SplitLog` 命令：

该命令已在 `Task:Manager` 中自动注册，每分钟执行一次。

**工作原理：**
1. 读取 `fee-access.log` 文件
2. 按时间戳将日志分割到 `fee-access/YYYY/MM/DD/HH/mm/log` 目录结构
3. 清空原日志文件

**注意事项：**
- 确保 Nginx 日志路径配置正确
- 日志文件命名必须为 `fee-access.log`
- 该命令仅在 Windows 系统执行，Linux 系统会自动跳过

```

### 5.7 Nginx 配置

#### 5.7.1 配置日志收集

编辑 Nginx 配置文件（例如：`/etc/nginx/conf.d/fee.conf`）：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # API 接口
    location /api {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # SDK 打点接口
    location /log.gif {
        # 记录到单独的日志文件
        access_log /var/log/nginx/fee-access.log main;
        
        # 返回1x1透明GIF
        default_type image/gif;
        return 200 '\x47\x49\x46\x38\x39\x61\x01\x00\x01\x00\x80\x00\x00\x00\x00\x00\x00\x00\x00\x00\x21\xf9\x04\x01\x00\x00\x00\x00\x2c\x00\x00\x00\x00\x01\x00\x01\x00\x00\x02\x02\x44\x01\x00\x3b';
    }
}
```

#### 5.7.2 配置日志轮转

创建 `/etc/logrotate.d/fee`：

```
/var/log/nginx/fee-access.log {
    daily
    rotate 30
    compress
    delaycompress
    notifempty
    create 0640 www-data adm
    sharedscripts
    postrotate
        [ -f /var/run/nginx.pid ] && kill -USR1 `cat /var/run/nginx.pid`
    endscript
}
```

## 七、常见问题排查

### 7.1 Server 启动失败

**问题1：端口被占用**
```
Error: listen EADDRINUSE :::3000
```

**解决方案：**
```bash
# 查看占用端口的进程
lsof -i :3000  # Linux/Mac
netstat -ano | findstr :3000  # Windows

# 杀死进程
kill -9 <PID>  # Linux/Mac
taskkill /F /PID <PID>  # Windows

# 或修改端口配置
# 编辑 server/src/configs/app.js，修改 port 值
```

**问题2：MySQL 连接失败**
```
Error: connect ECONNREFUSED 127.0.0.1:3306
```

**解决方案：**
1. 检查 MySQL 是否启动：`systemctl status mysql`
2. 检查 MySQL 配置是否正确
3. 检查防火墙是否开放 3306 端口

**问题3：Redis 连接失败**
```
Error: connect ECONNREFUSED 127.0.0.1:6379
```

**解决方案：**
1. 检查 Redis 是否启动：`systemctl status redis`
2. 检查 Redis 配置是否正确
3. 临时方案：在 `alarm.js` 中添加 try-catch 容错处理

### 7.2 Client 启动失败

**问题1：依赖安装失败**
```
npm ERR! code EACCES
```

**解决方案：**
```bash
# 清除缓存
npm cache clean --force

# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
rm -rf node_modules package-lock.json
npm install
```

**问题2：编译报错**
```
Module not found: Error: Can't resolve 'xxx'
```

**解决方案：**
```bash
# 清除缓存并重新安装
rm -rf node_modules/.cache
npm install
```

### 7.3 数据库初始化失败

**问题1：SQL 语法错误**
```
ERROR 1064 (42000): You have an error in your SQL syntax
```

**解决方案：**
1. 确保删除了 `init.sql` 的前两行
2. 检查 MySQL 版本是否 >= 5.7
3. 检查字符集是否为 utf8mb4

**问题2：表已存在**
```
ERROR 1050 (42S01): Table 'xxx' already exists
```

**解决方案：**
```sql
-- 删除数据库重新创建
DROP DATABASE platform;
CREATE DATABASE platform DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 或修改生成SQL的参数，使用新的月份范围
npm run fee Utils:GenerateSQL 1 '2024-01' '2024-12' > init.sql
```

### 7.4 报警不触发

**问题：报警日志为空**

**排查步骤：**

1. **检查报警配置**
   ```sql
   SELECT * FROM t_o_alarm_config WHERE is_delete=0 AND is_enable=1;
   ```

2. **检查监控数据**
   ```sql
   SELECT COUNT(*) FROM t_o_monitor_2_YYYYMM 
   WHERE log_at >= UNIX_TIMESTAMP() - 60;
   ```

3. **检查 Redis**
   ```bash
   redis-cli KEYS plat_fe_fee_watch_alarm_*
   ```

4. **查看日志**
   ```bash
   tail -f server/log/command.log
   ```

5. **手动执行报警命令**
   ```bash
   npm run fee WatchDog:Alarm
   ```

**常见原因：**
- 监控数据时间不在查询范围内
- Redis 未启动导致冷却期检查失败
- 报警配置的时间范围过短

### 7.5 数据不更新

**问题：页面数据不更新**

**排查步骤：**

1. **检查 Task:Manager 是否运行**
   ```bash
   ps aux | grep Task:Manager
   ```

2. **检查定时任务日志**
   ```bash
   tail -f server/log/command.log | grep "registerTaskRepeatPer1Minute"
   ```

3. **手动执行数据汇总**
   ```bash
   npm run fee Summary:Error '2024-01-01 10:00' minute
   ```

4. **检查数据库数据**
   ```sql
   SELECT * FROM t_r_error_summary_2_YYYYMM ORDER BY create_time DESC LIMIT 10;
   ```

### 7.6 Windows 特有问题

**问题1：日志文件路径错误**
```
Error: ENOENT: no such file or directory
```

**解决方案：**
1. 确保路径使用正斜杠 `/`
2. 确保路径存在且有读取权限
3. 检查 Nginx 是否正在运行并生成日志

**问题2：进程管理困难**

**解决方案：**
使用 PM2 管理进程：
```powershell
npm install -g pm2
pm2 start pm2_fee_app.json --env development
pm2 start pm2_fee_task_manager.json --env development
```
