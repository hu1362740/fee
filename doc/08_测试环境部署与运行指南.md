# 测试环境部署与运行指南

## 一、概述

测试环境是介于开发环境和生产环境之间的验证环境，用于：

- **功能验证**：验证新功能是否正常工作
- **集成测试**：测试各模块之间的协作
- **性能测试**：验证系统在高负载下的表现
- **用户验收**：提供给业务方进行功能验收

本指南适用于在 Linux 服务器上部署和运行 Fee 监控系统的测试环境。

## 二、服务器配置要求

### 2.1 硬件配置

| 配置项 | 最低要求 | 推荐配置 |
|--------|----------|----------|
| **CPU** | 2 核 | 4 核+ |
| **内存** | 4 GB | 8 GB+ |
| **磁盘** | 50 GB SSD | 100 GB SSD |
| **网络** | 10 Mbps | 100 Mbps+ |

**说明：**
- 如果监控项目较多或数据量大，建议增加 CPU 和内存
- 磁盘空间需要根据数据量评估，建议定期清理历史数据
- SSD 磁盘可显著提升数据库查询性能

### 2.2 操作系统要求

| 操作系统 | 版本要求 | 推荐版本 |
|----------|----------|----------|
| **CentOS** | 7.x+ | CentOS 7.9 |
| **Ubuntu** | 18.04+ | Ubuntu 20.04 LTS |
| **Debian** | 10+ | Debian 11 |

**推荐：** CentOS 7.9 或 Ubuntu 20.04 LTS，稳定性好，社区支持完善。

### 2.3 软件依赖

| 软件 | 版本要求 | 用途 |
|------|----------|------|
| **Node.js** | 12.x+ | 运行环境 |
| **MySQL** | 5.7+ | 数据存储 |
| **Redis** | 5.0+ | 缓存、报警冷却期 |
| **Nginx** | 1.15+ | 反向代理、日志收集 |
| **PM2** | 最新稳定版 | 进程管理 |
| **Git** | 2.0+ | 代码拉取 |
| **Kafka**（可选） | 2.0+ | 高并发日志收集 |

```bash

sudo systemctl disable firewalld

# 或开放必要端口
sudo firewall-cmd --permanent --add-port=80/tcp    # Nginx
sudo firewall-cmd --permanent --add-port=3000/tcp  # Server API
sudo firewall-cmd --permanent --add-port=8080/tcp  # Client
sudo firewall-cmd --permanent --add-port=3306/tcp  # MySQL
```

### 3.3 安装 MySQL

#### 3.3.1 安装 MySQL 5.7

**CentOS/RHEL：**

```bash
# 添加 MySQL 官方仓库
sudo rpm -Uvh https://dev.mysql.com/get/mysql57-community-release-el7-11.noarch.rpm

# 安装 MySQL
sudo yum install -y mysql-community-server

# 启动 MySQL
sudo systemctl start mysqld
sudo systemctl enable mysqld

# 获取初始密码
sudo grep 'temporary password' /var/log/mysqld.log
```

**Ubuntu/Debian：**

```bash
# 安装 MySQL
sudo apt-get install -y mysql-server

# 启动 MySQL
sudo systemctl start mysql
sudo systemctl enable mysql

# 设置 root 密码
sudo mysql_secure_installation
```

#### 3.3.2 配置 MySQL

```bash
# 登录 MySQL
mysql -u root -p

# 修改 root 密码（使用初始密码登录后）
ALTER USER 'root'@'localhost' IDENTIFIED BY 'YourStrongPassword123!';

# 创建数据库
CREATE DATABASE platform DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 创建远程访问用户（可选）
CREATE USER 'fee'@'%' IDENTIFIED BY 'FeePassword123!';
GRANT ALL PRIVILEGES ON platform.* TO 'fee'@'%';
FLUSH PRIVILEGES;

# 退出
exit
```

#### 3.3.3 配置远程访问（可选）

编辑 MySQL 配置文件：

```bash
sudo vim /etc/my.cnf  # CentOS
# 或
sudo vim /etc/mysql/mysql.conf.d/mysqld.cnf  # Ubuntu
```

修改或添加：

```ini
[mysqld]
bind-address = 0.0.0.0
port = 3306
character-set-server = utf8mb4
collation-server = utf8mb4_unicode_ci
max_connections = 1000
```

重启 MySQL：

```bash
sudo systemctl restart mysqld  # CentOS
# 或
sudo systemctl restart mysql   # Ubuntu
```

```bash
sudo systemctl restart redis
```

#### 3.5.2 配置 Nginx

创建 Fee 项目配置：

```bash
sudo vim /etc/nginx/conf.d/fee.conf
```

添加以下配置：

```nginx
# 前端静态文件服务
server {
    listen 80;
    server_name fee-test.your-domain.com;

    # 前端静态文件
    location / {
        root /opt/fee-pro/client/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # API 接口代理
    location /api {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 项目 API 接口
    location ~ ^/project/\d+/api {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # SDK 打点日志
    location /log.gif {
        access_log /var/log/nginx/fee-access.log main;
        
        # 返回 1x1 透明 GIF
        default_type image/gif;
        return 200 '\x47\x49\x46\x38\x39\x61\x01\x00\x01\x00\x80\x00\x00\x00\x00\x00\x00\x00\x00\x00\x21\xf9\x04\x01\x00\x00\x00\x00\x2c\x00\x00\x00\x00\x01\x00\x01\x00\x00\x02\x02\x44\x01\x00\x3b';
        
        add_header Cache-Control 'no-cache, no-store, must-revalidate';
        add_header Pragma 'no-cache';
        add_header Expires '0';
    }

    # 日志格式
    log_format main '$remote_addr - $remote_user [$time_local] "$request" '
                    '$status $body_bytes_sent "$http_referer" '
                    '"$http_user_agent" "$http_x_forwarded_for"';

    access_log /var/log/nginx/fee-access.log main;
    error_log /var/log/nginx/fee-error.log;
}
```

验证配置：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

#### 3.5.3 配置日志轮转

创建日志轮转配置：

```bash
sudo vim /etc/logrotate.d/fee
```

添加以下内容：

```
/var/log/nginx/fee-*.log {
    daily
    rotate 30
    compress
    delaycompress
    notifempty
    create 0640 nginx adm
    sharedscripts
    postrotate
        [ -f /var/run/nginx.pid ] && kill -USR1 `cat /var/run/nginx.pid`
    endscript
}
```

## 五、服务启动与管理

### 5.1 使用 PM2 管理服务

#### 5.1.1 安装 PM2

```bash
sudo npm install -g pm2
```

#### 5.1.2 启动 Server 服务

```bash
cd /opt/fee-pro/server

pm2 start pm2_fee_app.json --env testing

# 查看状态
pm2 status

# 查看日志
pm2 logs fee-app
```

#### 5.1.3 启动 Task:Manager

```bash
cd /opt/fee-pro/server

# 启动任务调度
pm2 start pm2_fee_task_manager.json --env testing

# 查看状态
pm2 status
```

#### 5.1.4 设置开机启动

```bash
# 生成开机启动脚本
pm2 startup

# 保存当前进程列表
pm2 save

# 验证
pm2 list
```

#### 5.1.5 PM2 常用命令

```bash
# 查看所有进程
pm2 list

# 查看进程详情
pm2 show fee-app

# 重启服务
pm2 restart fee-app
pm2 restart fee-task-manager

# 停止服务
pm2 stop fee-app
pm2 stop fee-task-manager

# 删除服务
pm2 delete fee-app
pm2 delete fee-task-manager

# 查看日志
pm2 logs fee-app
pm2 logs fee-task-manager

# 清空日志
pm2 flush

# 监控面板
pm2 monit
```

### 5.2 使用脚本管理（备选方案）

### 7.2 日志管理

#### 7.2.1 日志轮转配置

已配置 Nginx 日志轮转，Server 日志也需要轮转：

创建 `/etc/logrotate.d/fee-server`：

```
/opt/fee-pro/server/log/*.log {
    daily
    rotate 30
    compress
    delaycompress
    notifempty
    create 0644 $USER $USER
    sharedscripts
    postrotate
        pm2 reloadLogs
    endscript
}
```

#### 7.2.2 清理旧日志

```bash
# 手动清理 30 天前的日志

cd /opt/fee-pro/server
npm run fee Utils:CleanOldLog
```

### 7.3 数据备份

#### 7.3.1 MySQL 备份

创建备份脚本 `/opt/fee-pro/backup_mysql.sh`：

```bash
#!/bin/bash

# 备份目录
BACKUP_DIR="/opt/fee-pro/backup/mysql"
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="fee_platform_${DATE}.sql"

# 创建备份目录
mkdir -p ${BACKUP_DIR}

# 执行备份
mysqldump -u fee -p'FeePassword123!' platform > ${BACKUP_DIR}/${BACKUP_FILE}

# 压缩
gzip ${BACKUP_DIR}/${BACKUP_FILE}

# 删除 30 天前的备份
find ${BACKUP_DIR} -name "*.sql.gz" -mtime +30 -delete

echo "Backup completed: ${BACKUP_FILE}.gz"
```

设置定时任务：

```bash
# 添加定时任务
crontab -e

# 每天凌晨 2 点执行备份
0 2 * * * /opt/fee-pro/backup_mysql.sh
```

#### 7.3.2 Redis 备份

Redis 已配置自动持久化，也可以手动备份：

```bash
# 触发 RDB 快照
redis-cli -a YourRedisPassword123! BGSAVE

# 复制 RDB 文件
cp /var/lib/redis/dump.rdb /opt/fee-pro/backup/redis/dump_$(date +%Y%m%d).rdb
```

## 八、常见问题处理

### 8.1 服务启动失败

**问题1：PM2 启动失败**

```bash
# 查看详细错误
pm2 logs fee-app --err

# 检查端口占用
netstat -tlnp | grep 3000

# 检查配置文件
cat /opt/fee-pro/server/pm2_fee_app.json
```

**解决方案：**

```bash
# 杀死占用端口的进程
kill -9 $(lsof -t -i:3000)

# 或修改端口配置
vim /opt/fee-pro/server/src/configs/app.js
# 修改 port 值

# 重启服务
pm2 restart fee-app
```

**问题2：MySQL 连接失败**

```bash
# 检查 MySQL 状态
sudo systemctl status mysqld

# 检查 MySQL 配置
cat /opt/fee-pro/server/src/configs/mysql.js

# 测试连接
mysql -u fee -p'FeePassword123!' platform
```

**解决方案：**

```bash
# 启动 MySQL
sudo systemctl start mysqld

# 检查用户权限
mysql -u root -p
GRANT ALL PRIVILEGES ON platform.* TO 'fee'@'%';
FLUSH PRIVILEGES;
```

**问题3：Redis 连接失败**

```bash
# 检查 Redis 状态
sudo systemctl status redis

# 检查 Redis 配置
cat /opt/fee-pro/server/src/configs/redis.js

# 测试连接
redis-cli -a YourRedisPassword123! ping
```

**解决方案：**

```bash
# 启动 Redis
sudo systemctl start redis

# 检查 Redis 配置
sudo vim /etc/redis.conf
# 确保 bind 和 requirepass 配置正确
```

### 8.2 数据不更新

**问题：页面数据不更新**

**排查步骤：**

1. 检查 Task:Manager 是否运行：
   ```bash
   pm2 list | grep fee-task-manager
   ```

2. 检查任务日志：
   ```bash
   tail -f /opt/fee-pro/server/log/command.log
   ```

3. 手动执行数据汇总：
   ```bash
   cd /opt/fee-pro/server
   npm run test_fee Summary:Error '2024-06-12 10:00' minute
   ```

4. 检查数据库数据：
   ```sql
   SELECT * FROM t_r_error_summary_2_202406 
   ORDER BY create_time DESC LIMIT 10;
   ```

**解决方案：**

```bash
# 重启 Task:Manager
pm2 restart fee-task-manager

# 检查定时任务是否注册
tail -f /opt/fee-pro/server/log/command.log | grep "registerTaskRepeatPer1Minute"
```

### 8.3 报警不触发

**问题：报警日志为空**

**排查步骤：**

1. 检查报警配置：
   ```sql
   SELECT * FROM t_o_alarm_config WHERE is_delete=0 AND is_enable=1;
   ```

2. 检查监控数据：
   ```sql
   SELECT COUNT(*) FROM t_o_monitor_2_202406 
   WHERE log_at >= UNIX_TIMESTAMP() - 60;
   ```

3. 检查 Redis 冷却期：
   ```bash
   redis-cli -a YourRedisPassword123! KEYS plat_fe_fee_watch_alarm_*
   ```

4. 手动执行报警命令：
   ```bash
   cd /opt/fee-pro/server
   npm run test_fee WatchDog:Alarm
   ```

**解决方案：**

```bash
# 清除 Redis 冷却期
redis-cli -a YourRedisPassword123! DEL plat_fe_fee_watch_alarm_1

# 调整报警配置
mysql -u fee -p'FeePassword123!' platform
UPDATE t_o_alarm_config SET time_range_s = 300 WHERE id = 2;
```

### 8.4 性能问题

**问题1：API 响应慢**

**排查步骤：**

```bash
# 查看慢查询
mysql -u fee -p'FeePassword123!' platform
SHOW VARIABLES LIKE 'slow_query_log';
SHOW GLOBAL STATUS LIKE 'Slow_queries';

# 检查索引
SHOW INDEX FROM t_o_monitor_2_202406;
```

**解决方案：**

```sql
-- 添加索引
ALTER TABLE t_o_monitor_2_202406 ADD INDEX idx_log_at (log_at);
ALTER TABLE t_o_monitor_2_202406 ADD INDEX idx_error_name (error_name);
```

**问题2：内存占用高**

**排查步骤：**

```bash
# 查看 PM2 进程内存使用
pm2 list

# 查看 Node.js 堆内存
pm2 show fee-app
```

**解决方案：**

```bash
# 增加 Node.js 内存限制
vim /opt/fee-pro/server/pm2_fee_app.json
# 添加 node_args: ["--max-old-space-size=4096"]

# 重启服务
pm2 restart fee-app --update-env
```

**问题：磁盘空间不足**


## 九、版本更新

### 9.1 更新流程

#### 9.1.1 备份当前版本

```bash
# 备份代码
cd /opt
cp -r fee-pro fee-pro-backup-$(date +%Y%m%d)

# 备份数据库
mysqldump -u fee -p'FeePassword123!' platform > /opt/fee-pro/backup/mysql/backup_$(date +%Y%m%d).sql
```

#### 9.1.2 拉取新版本

```bash
cd /opt/fee-pro

# 拉取最新代码
git pull origin master

# 或切换到指定版本
git checkout v1.2.0
```

#### 9.1.3 安装新依赖

```bash
# 更新 Server 依赖
cd /opt/fee-pro/server
npm install --production

# 更新 Client 依赖并构建
cd /opt/fee-pro/client
npm install
npm run build
```

#### 9.1.4 执行数据库迁移

如果有数据库变更：

```bash
cd /opt/fee-pro/server

# 生成新表
npm run test_fee Utils:GenerateSQL 1 '2024-07' '2024-12' > migrate.sql

# 执行迁移
tail -n +3 migrate.sql | mysql -u fee -p'FeePassword123!' platform
```

#### 9.1.5 重启服务

```bash
cd /opt/fee-pro/server

# 重新编译
npm run build

# 重启服务
pm2 restart all

# 或逐个重启
pm2 restart fee-app
pm2 restart fee-task-manager
```

### 9.2 回滚流程

如果新版本有问题，需要回滚：

```bash
# 停止当前服务
pm2 stop all

# 恢复代码
cd /opt
rm -rf fee-pro
mv fee-pro-backup-20240612 fee-pro

# 恢复数据库
mysql -u fee -p'FeePassword123!' platform < /opt/fee-pro/backup/mysql/backup_20240612.sql

# 重启服务
cd /opt/fee-pro/server
pm2 start all
```
