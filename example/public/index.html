闭环说明

页面端 SDK 发出的 Image 请求会被桥接到 example 收集器，收集器写入 Nginx-like 日志和 server 可消费的 Kafka JSON 日志。

  1. 业务页面调用 `window.dt` 的错误、性能、行为、信息接口。
  2. `sdk-bridge.js` 将 SDK 默认打点地址重定向到本地 `/dig`。
  3. `scripts/server.js` 记录 `example/logs/nginx/fee-access.log`，并写入 `server/log/kafka/json`。
  4. 运行 `server` 的 `Parse:*` / `Summary:*` 命令后，client 管理后台即可查看对应图表。
