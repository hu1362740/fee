打点目标 -
  1. 打开浏览器 Network，过滤 `dig`，能看到 SDK 发出的 Image 请求。
  2. 确认本机 Nginx 的 `fee-access.log` 或 `access.log` 中出现 `/dig?d=...`。
  3. 运行 `server` 的 `SaveLog:Nginx`、`Parse:*`、`Summary:*` 命令。
  4. 登录 `client`，在模板项目中查看错误、性能、UV/PV、行为等数据。

闭环说明

页面端 SDK 发出的 Image 请求直接进入本机 Nginx，再由 server 侧命令完成日志落地、解析、汇总和 client 展示。

  1. 业务页面调用 `window.dt` 的错误、性能、行为、信息接口。
  2. SDK 使用业务方通过 `dt.set({ reportUrl })` 配置的地址发送 1px Image 请求。
  3. 本机 Nginx 接收 `/dig?d=...` 并写入 access log。
  4. `server` 通过 `SaveLog:Nginx` 将 access log 转为 `server/log/kafka/json`。
  5. 运行 `server` 的 `Parse:*` / `Summary:*` 命令后，client 管理后台即可查看对应图表。
